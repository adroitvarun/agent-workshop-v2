# Exam prep planner

Follow these steps in order.

1. Find out the exam date. If it isn't given, check the notice board. If it still isn't known, ask.
2. Find out how many hours a day the student can study. If it isn't given, assume 2.
3. Load `references/study-techniques.md` and use the techniques in it.
4. Write the plan as a table with the columns Day, Topic, Technique, and Hours.

## Rules

- Spend the last day only on practice questions and rest. No new topics.
- Put the hardest topics first, while there is still time to ask for help.
- End with one sentence of honest encouragement. Don't overpromise.
