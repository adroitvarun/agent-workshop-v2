# Group project planner

1. Ask for the deadline and the team size, if they weren't given.
2. Break the project into 5 to 8 concrete tasks.
3. Give each person a fair share, and pair people on the hardest task.
4. Set an internal deadline 2 days before the real one.
5. Reply with a table with the columns Task, Owner, and Due.

## Rules

- Never leave a task without one named owner. Use "Person 1", "Person 2" if names aren't known.
- Include a final task for reviewing the whole project together.
